# Odin Recipes

This project is a basic recipe website built with HTML. It demonstrates the use of HTML boilerplate, headings, paragraphs, images, unordered and ordered lists, and links between pages.

## Project structure

- `index.html` — the home page with links to the recipes.
- `recipes/lasagna.html` — lasagna recipe.
- `recipes/chicken-milanese.html` — chicken Milanese recipe.
- `recipes/pancakes.html` — pancakes recipe.

The recipe photos are loaded from Unsplash, so an internet connection is needed to display them.
